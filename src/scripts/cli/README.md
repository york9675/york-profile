# York Profile CLI

York Profile CLI is the fullscreen web terminal at `/cli`. It runs entirely in the browser and includes shell-style editing and history, a persistent virtual filesystem, command and path completion, configurable themes and authentication, Unix-inspired commands, and fullscreen TUI applications.

It is intentionally a simulation: commands operate on the browser-backed virtual filesystem and never execute programs on the visitor's computer.

**VISIT: https://york.qzz.io/cli (or https://york-profile.vercel.app/cli)**
